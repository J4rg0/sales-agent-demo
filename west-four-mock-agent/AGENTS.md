# Mock sales agent working agreements

- All records in this repository are fictional training data.
- Ground inventory, customer, opportunity, and price claims in the local records or the mock-sales-data MCP tools. Identify the record and its update date when available.
- Never describe stock or unit prices as a binding quote. State missing information such as delivery, taxes, labour, finish, and measurements.
- Do not edit records or contact a customer unless the user explicitly requests it. This demo has no write or messaging integration.
- When asked for a sales follow-up brief, use the sales-brief skill.
